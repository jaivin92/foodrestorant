# Foodrestorant

Angular 21 application scaffold for a restaurant website.

## Folder structure

```text
public/
  fonts/
  images/
  data/
  i18n/
src/
  app/
  index.html
  main.ts
  styles.scss
```

- `public/` contains public assets copied directly into the build output.
- `public/fonts/` is reserved for font files.
- `public/images/` is reserved for images.
- `public/data/` is reserved for static JSON or other data files.
- `public/i18n/` is reserved for translation files.
- `src/` contains Angular source code.

## Development

Install dependencies and start the development server:

```bash
npm install
npm start
```

Build for production:

```bash
npm run build
```
